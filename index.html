🎯 大师选饵七步法

1读水读环境：确认钓点类型（码头/礁石/沙滩/河口），观察水流、水深、水质
2定目标鱼和水层：根据季节、潮汐、钓点确定目标鱼种和作钓水层
3选饵型：亮片/软饵/米诺/活饵，根据目标鱼和水层选择
4定克重：根据水深、水流、风力选择合适克重，确保能到达目标水层
5定颜色：根据光线、水质选择颜色（清水用自然色，浑水用亮色）
6定手法：根据鱼活性选择收线速度和动作（慢收/抽动/飘落）
7试钓迭代：先试一种方案，无口及时调整饵型、克重、颜色、手法

潮汐窗口总纲

黄金窗口：涨潮前1h - 满潮、落潮初期（刚退1-2h）
一般窗口：半潮（涨/退50%）
最差窗口：死潮/平潮顶（高低潮前后30min）
大潮vs小潮：大潮（朔望潮）水流强、鱼活跃、咬口窗口长；小潮水流慢、需精细作钓

安全守则

- 礁石岸穿防滑鞋、戴救生衣，结伴同行
- 注意离岸流（Rip），被卷走时平行海岸游
- 关注BOM风速和海浪预警，大风大浪不出钓
- 夜间作钓至少2人同行，告知家人位置

软饵（铅头钩钓组）

- 3寸桨尾+7-10g铅头：浅水底层、礁石耐挂、Flathead首选
- 4寸桨尾+14g铅头：深水底层、Flathead/Bream
- 操作：贴底慢拖+小跳+停顿；咬口多在下落飘落时
- 优势：礁石区耐挂底（vs亮片），鱼咬得深

调漂要领

- 咬铅分段配置（不要集中一颗），让饵自然下沉
- 标准状态：阿波刚好露出顶部，风浪大换大一号漂
- 钓棚深度 = 棉线结到钩的距离，略深于实际水深20-30cm

咬钩识别

- 阿波快速下沉（黑漂）-> 大鱼吞饵，立刻扬竿
- 阿波横向走线 -> 鱼衔饵游走，等1-2秒扬竿
- 阿波上下点动 -> 小鱼啄饵或大鱼试探，耐心等

- 夜钓大物：氟碳25‑30lb，80‑150cm
- 沙滩远投：氟碳16‑25lb，60‑100cm（双钩）

虾仁挂饵方法

1. 整只虾挂法：钩从虾头刺入，穿过虾身，钩尖从虾尾1/3处穿出，虾身自然弯曲
2. 去壳虾仁：钩穿入2‑3次，让虾仁紧贴钩弯，钩尖微露
3. 分段挂法：大虾仁切2‑3段，每段穿钩，适合小鱼多的情况
4. 秘诀：挂钩后轻轻拉一下，确保饵不会轻易被鱼叼走；Circle钩钩尖一定要露出

核心操作要点

1. 抛投后收紧余线，竿尖保持微弯
2. Circle圆钩不要猛扬竿，看到出线后缓慢绷紧收线即自动刺鱼
3. 中鱼后第一时间把鱼拉出结构区（礁石/木桩）
4. 同位置20‑30分钟无口 -> 换标点或换饵
5. 滑铅坠必须通心可滑动，死铅鱼会吐饵

打窝节奏：
‑ 浮漂钓：涨潮前30min开始打窝，每10‑15min补一小勺
‑ 沉底钓：钓前打2‑3勺沉底窝，中鱼后补一勺
‑ 路亚：不需要打窝，但可以抛洒少量碎虾引鱼

潮汐基础

‑ 成因：月球引力+太阳引力共同作用
‑ 周期：约12小时25分钟（半日潮），每天延迟约50分钟
‑ 一天通常2次高潮+2次低潮

大潮vs小潮判断

潮型月相潮差鱼情作钓建议
大潮(Spring)新月/满月（朔望潮）最大（1.5m+）最好水流强、咬口窗口长，抓紧黄金时段
中潮(Mid)盈凸月/亏凸月中等（0.8‑1.5m）好水流适中，全天可钓
小潮(Neap)上弦月/下弦月较小（0.4‑0.8m）一般水流慢，精细作钓，找结构边
死潮(Dead)小潮最低点极小（<0.4m）最差几乎无口，建议休息

作钓窗口

最佳窗口：涨潮前1小时 ‑> 满潮+1小时（鱼随潮水涌入近岸）
次佳窗口：落潮初期1‑2小时（鱼随退潮撤出，在深槽集中）
最差窗口：死潮/平潮顶（高低潮前后30分钟，水流静止）
转流瞬间：平潮转流后15‑30分钟，往往出现咬口高峰
