🎯 大师选饵七步法

1读水读环境：确认钓点类型（码头/礁石/沙滩/河口），观察水流、水深、水质
2定目标鱼和水层：根据季节、潮汐、钓点确定目标鱼种和作钓水层
3选饵型：亮片/软饵/米诺/活饵，根据目标鱼和水层选择
4定克重：根据水深、水流、风力选择合适克重，确保能到达目标水层
5定颜色：根据光线、水质选择颜色（清水用自然色，浑水用亮色）
6定手法：根据鱼活性选择收线速度和动作（慢收/抽动/飘落）
7试钓迭代：先试一种方案，无口及时调整饵型、克重、颜色、手法

调漂要领

- 咬铅分段配置（不要集中一颗），让饵自然下沉
- 标准状态：阿波刚好露出顶部，风浪大换大一号漂
- 钓棚深度 = 棉线结到钩的距离，略深于实际水深20-30cm

咬钩识别

- 阿波快速下沉（黑漂）-> 大鱼吞饵，立刻扬竿
- 阿波横向走线 -> 鱼衔饵游走，等1-2秒扬竿
- 阿波上下点动 -> 小鱼啄饵或大鱼试探，耐心等

虾仁挂饵方法

1. 整只虾挂法：钩从虾头刺入，穿过虾身，钩尖从虾尾1/3处穿出，虾身自然弯曲
2. 去壳虾仁：钩穿入2-3次，让虾仁紧贴钩弯，钩尖微露
3. 分段挂法：大虾仁切2-3段，每段穿钩，适合小鱼多的情况
4. 秘诀：挂钩后轻轻拉一下，确保饵不会轻易被鱼叼走；Circle钩钩尖一定要露出

核心操作要点

1. 抛投后收紧余线，竿尖保持微弯
2. Circle圆钩不要猛扬竿，看到出线后缓慢绷紧收线即自动刺鱼
3. 中鱼后第一时间把鱼拉出结构区（礁石/木桩）
4. 同位置20-30分钟无口 -> 换标点或换饵
5. 滑铅坠必须通心可滑动，死铅鱼会吐饵

潮汐基础

- 成因：月球引力+太阳引力共同作用
- 周期：约12小时25分钟（半日潮），每天延迟约50分钟
- 一天通常2次高潮+2次低潮

大潮vs小潮判断

潮型月相潮差鱼情作钓建议
大潮(Spring)新月/满月（朔望潮）最大（1.5m+）最好水流强、咬口窗口长，抓紧黄金时段
